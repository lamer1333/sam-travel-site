# SAM TRAVEL — панели владельца и маркетолога

`admin.html` — одна панель с двумя рабочими пространствами: **Владелец** и **Маркетинг**.
Что видит человек, решает его роль (её назначает владелец). Бэкенд — тот же Supabase,
что и для входа на сайт: своего сервера по-прежнему нет.

**Посмотреть без настройки:** `admin.html?demo` — сгенерированное агентство, 120 дней
трафика, ~400 заявок. В полосе сверху можно переключиться на роль менеджера или маркетолога.
Сайт с данными демо-панели: `index.html?cms=demo`. Заявка, отправленная с такого сайта
в соседней вкладке, прилетает в демо-панель уведомлением.

---

## Запуск (15 минут)

1. **База.** Supabase → SQL Editor → вставить весь `supabase/admin.sql` → Run.
   Запускать после `schema.sql`; повторный запуск безопасен. Миграция переносит в базу
   текущие туры, контакты и реквизиты сайта — после неё сайт выглядит так же, как сейчас.
2. **Владелец.** Зарегистрируйтесь на сайте (меню → Войти), затем в SQL Editor:
   ```sql
   update public.profiles set role = 'admin'
   where id = (select id from auth.users where email = 'ваш@email');
   ```
   Остальных владелец назначает уже в панели: «Клиенты и команда» → email → роль.
3. **Проверка.** Открыть `admin.html`, войти. На сайте отправить тестовую заявку — она
   появится в «Заявках» со звуком и уведомлением.
4. **Telegram (по желанию).** Новая заявка → сообщение в чат с кнопками «WhatsApp» и
   «Открыть в панели». Инструкция в шапке `supabase/functions/lead-notify/index.ts`:
   бот у @BotFather → секреты → `supabase functions deploy lead-notify --no-verify-jwt` →
   Database Webhook на вставку в `leads`.
5. **Перед запуском** откройте «Готовность сайта» — панель сама перечислит, что осталось
   (образцы номеров лицензии, отзывы, фото менеджеров, SEO на RU/HY, ID пикселей…).

## Роли

| Роль | Что доступно |
|---|---|
| **Владелец** (`admin`) | Всё. Роли, реквизиты, контакты, шаблоны ответов, журнал изменений, готовность сайта, удаление заявок |
| **Менеджер** (`manager`) | Сводка, заявки, клиенты и команда (без ролей), бронирования |
| **Маркетолог** (`marketer`) | Трафик, кампании, промо, промокоды, подписчики, туры/отзывы/рилсы, SEO и ID пикселей. Количество заявок по каналам — да, **телефоны клиентов — нет** |

Права проверяет база (RLS + проверки в функциях), а не только интерфейс.

## Что умеет

**Владелец**
- Сводка: выручка, заявки, конверсия, средний чек, медиана первого ответа, прогноз по
  предложениям, причины отказов, рейтинг менеджеров, интерес к направлениям, когда пишут клиенты.
- Заявки: канбан с перетаскиванием и таблица, фильтры и быстрые срезы («Мои», «Ждут дольше
  N мин», «Перезвонить сегодня»), таймер ответа на каждой карточке, повторные обращения по
  номеру, WhatsApp по шаблону с подстановкой имени/направления, история, заметки, теги, сумма
  сделки, причина отказа, массовые действия, CSV, ручное добавление звонков и визитов,
  звук + уведомление браузера + счётчик во вкладке при новой заявке.
- Контент сайта: горящие туры (EN/RU/HY, фото, цена «от», авто-снятие по дате, порядок
  перетаскиванием, живое превью карточки), отзывы с модерацией, команда, рилсы, цифры.
- Контакты и реквизиты: телефон, WhatsApp, почта, соцсети, адрес на трёх языках, лицензия,
  страховка, маржа агентства, рабочее время и норматив ответа. Меняются по всему сайту сразу.
- Шаблоны ответов WhatsApp, журнал изменений с построчным diff, проверка готовности сайта.

**Маркетолог**
- Трафик и конверсии: посещения, вовлечённость, воронка с подсказкой слабого места, каналы
  с конверсией и выручкой, дочитываемость блоков, клики по кнопкам, интерес к турам,
  устройства и языки, тепловая карта по часам. Своя аналитика, без cookie — видит всех.
- Кампании и UTM: конструктор ссылок с шаблонами каналов, QR-код в PNG, расход, заявки,
  продажи, цена заявки и **ROMI от прибыли** (выручка × маржа, а не оборот), поиск меток без кампании.
- Баннеры и поп-апы: полоса или окно, 3 языка, 4 темы, промокод, расписание, таргетинг по языку /
  устройству / рекламной кампании, триггер (задержка, половина страницы, уход со страницы),
  частота показа, CTR, предпросмотр на живом сайте, видимый только автору.
- Промокоды: один или пачка персональных, лимиты, сроки, использование в заявках, CSV.
- Подписчики: только давшие согласие, рост базы, сегменты по языку, выгрузка для Brevo.
- SEO и пиксели: title/description на трёх языках со сниппетом Google и превью для
  мессенджеров, ID GA4 и Meta Pixel без правки кода.

**Для обоих:** поиск и команды по ⌘K / Ctrl K (разделы, действия, клиенты по имени и
телефону), светлая и тёмная тема, работает с телефона.

## Как сайт связан с панелью

| Файл | Роль |
|---|---|
| `js/cms.js` | Один запрос `public_site()` → контакты, реквизиты, туры, отзывы, команда, рилсы, SEO, промо. Форма заявки → `submit_lead()` |
| `js/track.js` | Аналитика без cookie: визит живёт в памяти вкладки, в базу уходят события пачками |
| `js/analytics.js` | GA4 / Pixel: ID берутся из панели, грузятся только после «Принять» |

Встроенный в HTML текст — запасной вариант: блок заменяется, только если в базе есть
опубликованные записи. Нет связи с базой — сайт остаётся как есть, а форма заявки открывает
WhatsApp с тем же текстом, так что заявка не теряется.

## Безопасность

- Посетители не пишут в таблицы напрямую: заявки и события идут через функции с проверками
  (ловушка для ботов, склейка дублей за 3 минуты, лимит на поток заявок).
- Исправлены две дыры в `schema.sql`: представление `marketing_audience` отдавало email
  подписчиков любому по REST API; политика `coupons: read active` позволяла перечислить все
  промокоды. Теперь — `audience_list()` для маркетинга и `check_coupon()` по одному коду.
- Маржа агентства не уходит на публичный сайт.
- Фото из панели ужимаются до 1600 px и хранятся в бакете `media` (писать может только команда).

## Ограничения

- Интерфейс панели — на русском (строки в коде разделов).
- «Посещение» = одно открытие страницы; уникальных людей без cookie не посчитать.
- Регион проекта Supabase — Сидней (~300 мс до Армении): панель и сайт работают, но
  быстрее будет проект во Франкфурте.
- Рассылки панель не отправляет — только готовит сегмент и выгрузку для Brevo.
