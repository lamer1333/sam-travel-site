SAM TRAVEL — сайт (финальная версия)
=====================================

Одностраничный сайт турагентства SAM TRAVEL (Ереван).
Статический: чистые HTML / CSS / JS, без сборки и без бэкенда.


КАК ПОСМОТРЕТЬ
--------------
1) Локально — открыть index.html двойным кликом в браузере.
   Важно: держите папки css/, js/, img/ и файл sam-logo.png рядом с index.html.

2) Рекомендуется — отдавать через любой статический хостинг
   (или локальный сервер: в папке выполнить  python3 -m http.server 8000
   и открыть http://localhost:8000 ). Так корректно работают QR-код и кэш.


СТРУКТУРА
---------
index.html          разметка страницы + иконки (SVG-спрайт)
css/styles.css      все стили
js/app.js           логика (навигация, формы, подбор тура, чек-лист виз, языки)
js/i18n.js          словарь интерфейса (EN / RU / HY)
js/pages.js         контент страниц-оверлеев (EN / RU / HY)
js/shader.js        WebGL-фон «волны» (при отсутствии WebGL — CSS-градиент)
img/                фоновые фото (webp): герой (небо/Арарат/равнина) и морская полоса
sam-logo.png        логотип (раздел «О нас»)


ЧТО НУЖЕН ИНТЕРНЕТ
------------------
Основная часть сайта работает офлайн. Интернет нужен для:
  - рила в Instagram (встраиваемый блок в разделе «Блог»);
  - библиотеки QR-кода (qrcode с CDN, для чек-листа виз);
  - переходов в WhatsApp и на Instagram (внешние ссылки).


ОСОБЕННОСТИ ЭТОЙ ВЕРСИИ
-----------------------
  - Параллакс героя — на нативном CSS scroll-timeline (animation-timeline),
    без JS-библиотек. В старых браузерах без поддержки — статичный герой.
  - Фото вынесены в отдельные файлы (img/) и кэшируются браузером.
  - Безопасность: у CDN-скрипта проверка целостности (SRI) и политика
    Content-Security-Policy в <head>.
  - Бэкенд — Supabase (без своего сервера): вход и личный кабинет
    (SETUP-AUTH.md), заявки, контент, аналитика и панель управления
    admin.html для владельца и маркетолога (SETUP-ADMIN.md).
    Демо панели без настройки: admin.html?demo


ПЕРЕД ПУБЛИКАЦИЕЙ (опционально)
------------------------------
Мета-CSP не покрывает защиту от кликджекинга. На хостинге стоит добавить
HTTP-заголовки:  Content-Security-Policy: frame-ancestors 'none'
                 X-Frame-Options: DENY
