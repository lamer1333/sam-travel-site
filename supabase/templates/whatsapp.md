# Шаблоны сообщений WhatsApp для подачи в Meta

**Сейчас не используются.** Напоминания о вылетах отправляет человек со своего телефона
(ТЗ §4.12): система готовит список и текст, WhatsApp Cloud API не подключён. Этот файл —
заготовка на день, когда заказчик получит доступ к WhatsApp Business Platform: тогда
шаблоны ниже подаются на одобрение в WhatsApp Manager → Message templates.

Тексты те же, что в панели («Шаблоны ответов» → «Накануне вылета» / «После возвращения»),
только в формате Meta: подстановки нумеруются, необязательных кусков нет.

- `{{1}}` — имя клиента (первое слово)
- `{{2}}` — направление на языке клиента

Категория обоих шаблонов — **Utility** (сообщение о купленной поездке, не реклама).
Отправлять можно только тем, у кого в продаже стоит галочка «Клиент согласен получать
сообщения в WhatsApp» (`leads.wa_opt_in`).

## `flight_tomorrow` — накануне вылета

| Язык | Код языка в Meta | Текст |
|---|---|---|
| Русский | `ru` | Здравствуйте, {{1}}! Завтра ваш вылет в {{2}}. Желаем хорошего полёта и отличного отдыха! SAM TRAVEL |
| English | `en` | Hello, {{1}}! Your flight to {{2}} is tomorrow. Have a great flight and a wonderful holiday! SAM TRAVEL |
| Հայերեն | `hy` | Բարև ձեզ, {{1}}։ Վաղը ձեր թռիչքն է՝ {{2}}։ Մաղթում ենք բարի թռիչք և հիանալի հանգիստ։ SAM TRAVEL |

Пример для проверки Meta: `{{1}}` = Мариам, `{{2}}` = Шарм-эль-Шейх.

## `welcome_back` — на следующий день после возвращения

| Язык | Код языка в Meta | Текст |
|---|---|---|
| Русский | `ru` | С возвращением, {{1}}! Надеемся, {{2}} понравился. Будем рады вашему отзыву |
| English | `en` | Welcome back, {{1}}! We hope you enjoyed {{2}}. We would be glad to hear your feedback |
| Հայերեն | `hy` | Բարի վերադարձ, {{1}}։ Հուսով ենք՝ {{2}} ուղևորությունը ձեզ դուր եկավ։ Ուրախ կլինենք ստանալ ձեր կարծիքը |

Ссылка для отзыва в шаблоне Meta — кнопкой «Visit website» (URL из «Контакты и реквизиты»
→ «Ссылка для отзыва»), а не текстом.

## Что сделать, когда придёт разрешение

1. Внести токен и ID номера в секреты Edge Functions.
2. Подать оба шаблона на трёх языках на одобрение.
3. Дописать вызов WhatsApp Cloud API в `send_reminder(id)` (`090_reminders.sql`) — это
   единственная точка отправки; статус `auto_sent` и поля `attempts`,
   `provider_response`, `auto_sent_at` в `wa_reminders` уже есть.
4. Разрешить режим `auto` в `wa_settings_guard` и включить переключатель «Отправлять
   автоматически» в «Контакты и реквизиты».

Армянский и английский тексты нужно вычитать носителю до подачи.
